# Stub Theme Build Tracker

> **Workflow per theme:**
> 1. `[ ]` Design HTML prototype (standalone file in `theme-designs/{slug}/`)
> 2. `[ ]` Review & sign off HTML
> 3. `[ ]` Convert to Blade — override views in `themes/{slug}/views/`
> 4. `[ ]` Extract CSS → `themes/{slug}/assets/css/style.css`
> 5. `[ ]` Wire helpers (`theme_*()` API, no `<x->` tags)
> 6. `[ ]` Smoke test all key pages
> 7. `[ ]` Done
