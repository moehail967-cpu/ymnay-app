Every task the user gives me is a **ticket** inside a **sprint**.

**Why:** User wants to never lose context across sessions. A running SPRINT.md file is the single source of truth.

**How to apply:**
1. On any new task (or group of tasks), open `/Users/m1/Desktop/localhost/nazmart/SPRINT.md`
2. If a sprint is already active, add the new ticket(s) to the current sprint table — do NOT start a new sprint unless the user explicitly says so
3. Set status to `🔄 In Progress` when starting, `✅ Done` when complete
4. If the user sends a follow-up mid-task, immediately add it as a new row (do not lose track of the original task)
5. Never delete rows — completed rows are the audit trail
6. Backlog section holds items not yet started
